## Overview

MFM2 is a multi-tap delay with a feedback matrix where each of four taps can feed back into any other tap, creating rich, evolving echo textures from simple repeats to Eventide-style pitch modulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **u-he MFM** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **4-Tap Matrix** | Route each tap output to any combination of other tap inputs |
| **Pitch Modulation** | Per-tap pitch modulation for shimmer and vibrato echo effects |
| **Diffusion Network** | Variable diffusion transforms clean repeats into dense reverb tails |
| **Tempo Sync** | All tap times sync to DAW BPM with musical note divisions |
